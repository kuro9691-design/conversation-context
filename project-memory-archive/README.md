# Project Memory Archive

Codexに登録されている小規模プロジェクト、Google Drive中心の制作プロジェクト、単独リポジトリを作らない資料群のコードと再利用可能な手順をまとめる非公開アーカイブ。

## 保存するもの

- プログラム、スクリプト、設定例
- `AGENTS.md`、`CLAUDE.md`、一般化できる`CONTEXT.md`
- 制作手順、設計書、プロンプト、チェックリスト
- 大容量素材の保管場所と再現手順

## 保存しないもの

- 信用情報、口座・カード・借入・債務に関する個人データ
- パスワード、APIキー、認証Cookie、アクセストークン
- 動画、音声、PSD、Affinity、Illustrator、ZIPなどの大容量素材本体
- Google Driveの`.gdoc`など実体のない参照ファイル

各サブフォルダは元プロジェクト名を保ち、素材をGitHubへ複製しない場合も`PROJECTS.md`に保管場所と扱いを記録する。
