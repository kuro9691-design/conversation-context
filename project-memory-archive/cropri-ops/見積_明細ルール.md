# 見積の明細ルール(シルク・2026-10-09 決定)

**次の案件から適用**(MANABU決定)。山口圭一様のKIKYOU 100周年Tシャツは、自動見積もりアプリ(旧方式)の価格で freee Q-0000000047 を発行済み。

サイトの見積もり画面で仮の見積を出し、同じ明細でfreeeの正式な見積書を出す。

## 決まり
- **合計の基準** = ボディは**エスグラフィック**の5001価格 + プリント代と版代は**プラスワン(P1)**の公開価格表(どちらも税込)。
  - ラブラボはコミコミ価格で内訳が分からないため、基準・比較対象から外した(2026-10-09 ユーザー決定)。比較対象はエスグラフィック。
  - エスグラフィックの5001(https://www.esgraphic.co.jp/products/detail/1/500101 、税込、2026-10-09 確認): ホワイト S〜XL・ガールズ 880／XXL 1,100／XXXL 1,320／キッズ 836、カラー 957／1,298／1,463／913。
  - P1の価格表(https://www.p1-intl.com/guide/printprice.html 、税込。5001の目安1,925円と一致することで検算済み):
    - プリント代 1か所・1枚 [1色目/2色目以降1色ごと]: 1〜3枚 935/275、4〜9枚 682/275、10〜19枚 572/220、20〜49枚 440/143、50〜99枚 242/99、100〜299枚 165/66、300枚〜 88/55
    - 版代 1版(1色): 通常=P1の大版(28×33cm)9,900、特大=P1の特大版(40×40cm)14,300、そで=P1の小版 6,050
    - 特大は1枚+55円、そでは1枚1色ごとに+55円
  - **1枚から実際の枚数で計算**(10枚分ルールはやめた)。500枚以上は個別見積もり。
  - 袋詰め(55円)・送料(税込3万円以上無料)・完全データ入稿1,000円引きは cropri の設定(もとはラブラボにならったもの)。早割は入れない。
- **明細はKIKYOU型**: 本体(色・サイズ別)→ 版代(面別)→ シルクプリント代(**面別=前・後ろなどで分ける**)→ たたみ・袋詰め → 送料 → デザイン。
- **本体** = エスグラフィックの価格(税込)。税別 ホワイト800/カラー870/白XXL 1,000/白XXXL 1,200/カラーXXL 1,180/カラーXXXL 1,330/キッズ 白760・カラー830。
- **版代の行**: 通常・そで 6,000円/色、特大 8,000円/色(税別)。エドバンの版代と同じ額にする(ユーザー決定)。
- **プリント代** = (その面のP1基準の版代+プリント代(税別)− その面の版代の行)÷ 枚数。P1の版代との差額をプリント代の単価に含める。
- **デザイン**: データ作成・修正2回までは込み(0円の行を出す)。作り込みは**時給1,100円(税込)=1,000円(税別)**。
- **freeeは税別(外税)**。税込の価格を1.1で割り、1円未満は四捨五入。単価の丸めで、合計が基準から最大0.1%ほどずれる。

## 価格方針(2026-10-16 CONTEXT.md から移動)

CONTEXT.md には要点だけを残し、決めた内容・理由はここに置く。

- **シルクのお客様価格(2026-10-09 変更)**: ボディは**エスグラフィック**の5001価格(ホワイト880円・カラー957円など)、プリント代と版代は**プラスワン(P1)**の公開価格表に合わせる。袋詰め55円・送料(税込3万円以上無料)・完全データ入稿1,000円引きは cropri の設定。詳細は `見積_明細ルール.md`。
  - 理由: エドバンの原価で出すと、データ作成・お客様対応・発注作業の手間がまったく回収できない。ラブラボはコミコミ価格で内訳が分からないので、基準・比較対象から外した。**比較対象はエスグラフィック**(ボディ・版代・プリント代を税込で公開)。早割は入れない。
- **DTG・DTFは例外で「相場の高め」**(2026-09-29決定): ラブラボのDTG(インクジェット)・転写は相場より異様に高いので基準にしない。他社の価格表を見て相場の高め(エスグラフィックより少し下)に置き、**1枚から実際の枚数で計算**する。4枚以下のご注文には少量手数料(現在2,200円)を1回だけ加算し、4枚以下の合計は5枚で頼んだときの合計を上限とする(枚数を増やして合計が下がる逆転を作らない)。具体的な価格は PROGRESS.md。
- **デザイン料の考え方(ラブラボにならう)**: デザインデータ作成と修正2回までは価格に含める。3回目以降の修正・作り込みが必要なデザインは別途見積もり。完全データ入稿は1,000円引き。データは自分で完全データに整え、エドバンのデータ校正代(1デザイン3,000円〜)を発生させない。
- **シルクも1枚から実際の枚数で計算**(P1の1〜9枚の料金。10枚分ルールは廃止)。ただ版代がかかるので、少量はDTG・DTFを勧める(cropriは少量にも対応できるのが強み)。
- **「卸×1.7」はチェリー価格**(取引先チェリー君向け)。一般向けには使わない。
  - 価格はサイトもfreeeも**同じ基準(上のシルク基準)**に統一する。案件ごとに原価積み上げ方式と使い分けない(tshirt-estimate スキルもこれに合わせる)。
  - freeeは**税別(外税)**で入力する。サイトの税込価格を税別に換算する。
  - 明細は**KIKYOU型の内訳**。版代の行はエドバンと同じ6,000/8,000(税別)にし、基準との差額はプリント代の単価に含める。プリント代は面別(前・後ろ)。デザインの作り込みは時給1,100円(税込)。詳細と計算スクリプトは `見積_明細ルール.md`。
