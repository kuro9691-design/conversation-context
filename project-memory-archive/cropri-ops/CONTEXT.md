# cropri — CONTEXT

## 目的

Cropri の WordPress / Elementor TOPページを、50〜60年代アメリカンダイナー／レース看板のタイポグラフィを基調にしたアパレル／プリントサイトとして整備する。あわせて、オリジナルプリントの**見積もりサイト**として機能させる(サイト構成・価格の手本: ラブラボ https://www.rub-lab.com/ )。

## 事業の仕組みと価格の決め方(2026-09-29 ユーザー確認)

- **プリントは外注**: エドバンファクトリー(広島県福山市、https://edvan-factory.com/ 、業販価格表は取引先ログインが必要。ユーザーのChromeでログイン済み)。
  - 一般向け通販「オリジナルプリント特急便」(https://www.original-print.jp/ 、フジ総合印刷)はエドバンと同じ会社(ユーザー情報)。仕入先の直販なので、価格の比較対象にはしない。
- **Tシャツ等のボディは黒杭デザインが仕入れ**: ユナイテッドアスレ C.A.B. Web(https://order.united-athle.jp/ 、ユーザーのChromeでログイン済み)から仕入れ、エドバンへ直送する。配送は佐川急便を選ぶ。
- **発注はお客様の入金を確認してから**(前払い。ユーザー方針、変えない)。エドバンは受付完了後7日〜発送で、混雑時は延びる。お客様の使用日が近い案件は、入金前にエドバンへ空き状況を問い合わせ(発注ではない)、入金の目安日をお客様に伝える。
- **エドバンからの納品物を受け取ったら**(2026-10-20 ユーザー決定): 箱に入っているエドバンの伝票は原価が載っているので、お客様に見せず黒杭デザインで抜き取って保管する。商品は写真を撮って状態を確認し、写真はLINEで送ってもらう。
- **価格の要点**: シルクは、ボディ=エスグラフィックの5001価格、プリント代・版代=P1の公開価格表(税込)が基準。DTG・DTFは相場の高め・1枚から(4枚以下は少量手数料)。デザインは修正2回まで込み・完全データ入稿1,000円引き。「卸×1.7」はチェリー君向けで一般には使わない。正式見積はfreee(税別・KIKYOU型の明細)。
  - **理由・具体的な価格・計算方法は `見積_明細ルール.md` の「価格方針」**(2026-10-16 にこのファイルから移動)。価格を決める・見積もる作業のときだけ読む。
- **利益・原価はユーザー本人だけが見る**。お客様向けの見積もり画面(公開ページ)には原価・利益・仕入先の情報を一切入れない(JSのソースから見えてしまうため)。利益は別の社内用画面で確認する。
- 値段は他社と同じ価格帯なので、差をつけるのは価格以外(地元・デザイナー本人と直接やり取りできる・デザインの質・少量対応)。
- **売りにする機能: 刷り方ごとの価格曲線**(2026-09-29決定): 見積もり画面の「枚数と1枚あたりの価格」グラフで、シルク／DTG／DTFを枚数・絵の大きさ・色数を動かしながら比べられる。調べた8社にはなかったので、見積もり画面だけでなくトップや入口ページでも見出し付きで紹介し、「お客様に合う刷り方を正直に勧める店」として打ち出す。
- **狙う客層に「AIアート・ZINE・イベント物販の少量制作」を加える**(2026-09-29): 1枚から・濃色もDTFで割安・データ持ち込みOK・刷れるデータへの調整をデザイナー本人が見る。
- **見積の流れ(2026-10-09 ユーザー決定)**: サイトの見積もり画面で出すのは仮の見積。その明細を元に、正式な見積書はfreeeで出す。
  - 見積の内容とお客様の個人情報は、誰でも見られる場所に置かない。依頼の内容は管理者だけに届ける。
- 判断に迷ったら、内訳を公開している同じ価格帯の店(エスグラフィック・P1)と比べて決める(2026-10-09 にラブラボ基準から変更)。

## 固定方針

- 従来の「コラージュ／アート」路線は採用しない。
- アメリカ雑貨屋の看板やメニューを眺めるような、成人向けのポップで少し毒のある楽しさ。Tシャツ、ステッカー、プリント、ノベルティを主役にする。
- グラフィックよりタイポグラフィを主役にする。太い手描き文字、スクリプト、ブロック体、枠線、スターバースト、看板・メニューのような情報レイアウトを用いる。サイケデリック、子ども向け表現は使わない。
- UI自体は読みやすい現代的なレイアウトにし、ヴィンテージ感はグラフィックと印刷質感のアクセントに限定する。
- Cropriは飲食専門店ではなく、業種を限定しないアパレル／プリントブランド。
- 商品カテゴリーは現行Cropriの分類を継承する。主要導線は T-SHIRTS / SWEATSHIRTS / TOTE BAGS / CAPS / TOWELS & GOODS。
- キャッチコピーは元画像から切り出して配置する(テキストとして打ち直さない)。
- 見積もり計算機はプラグインではなく自作(軽いJS)。プリント方法(シルク／DTG／DTF)を選び、シルクは「位置×色数」、DTG・DTFは「位置×大きさ」で即時計算する。

## ビジュアル基準

- 承認済みトップ方向: 黒・生成り・赤橙を基調に、ラフなシルクスクリーン質感をアクセントとして用いる。
- 基本カラー: Paper #F5F3EE、Ink #111111、Signal #F04B2A(Elementorグローバルカラー「Cropri Paper / Cropri Ink / Cropri Signal」)。
- 価格曲線グラフの線の色: シルク #1F8A6B(緑)、DTG #E0482A(赤橙)、DTF #2F6DB5(青)。色覚の違いでも見分けられることを確認済み。
- 書体: 和文はGoogle Fonts「Noto Sans JP」のみ(グローバルフォント「Cropri JP」)。英字見出しは画像から切り出して配置。
- レイアウト目安: 最大コンテンツ幅 1440px、左右余白 PC 48px / Tablet 32px / Mobile 20px、PCヘッダー約96px。
- ロゴ運用: ヘッダーは太字ブロックのCROPRIロゴ、ヒーローは赤橙の太字ブロックCROPRIロゴ。手描きスクリプトロゴは採用しない。WordPress はSVGを拒否するためPNG。「FOR FOOD PEOPLE」は採用しない。
- 元画像切り出し系の反映は、比率を変えない(cover ではなく contain)。
