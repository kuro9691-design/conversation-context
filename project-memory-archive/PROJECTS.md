# 収録プロジェクト

| プロジェクト | 収録内容 | 素材の扱い |
|---|---|---|
| マイクロンメモリジャパン | 共有ルールと引き継ぎ | 素材なし |
| passengers | ポスター生成コード、配色HTML、台本 | 画像・音声は元フォルダ |
| cut up | プロジェクト参照情報 | 画像・音声のみのためGitHubへ複製しない |
| BUNK | 生成・整理・投稿準備コード、設計書 | 画像・動画はGoogle Drive |
| sunny-design | 制作メモ、市場資料生成コード | PDF・画像・出力物はGoogle Drive |
| 動画コラージュ | Blender・ポーズ抽出コード | 動画・画像・Blender実体はGoogle Drive |
| ネタ写真 | 生成ルール、パターンスキル、動画用コード | 写真・動画はGoogle Drive |
| cropri | 運用ルールと見積明細ルール | 顧客データ・控えはGoogle Drive |
| コラージュ | 制作ルール、SNS・リール調査資料 | PSD・PNG・動画はGoogle Drive |
| ★ | 空プロジェクト | 現時点で保存対象ファイルなし |
| 山口圭一 | Driveが現在接続されていないため参照のみ | 顧客素材は元Drive。再接続後にコード・手順だけ監査する |
