# PASSENGERS #1｜ElevenLabs 収録台本

設定：1970年、アルゼンチンまたはチリ。基本言語はスペイン語。  
生成方針：**1行ずつ別々に生成**し、編集時に間を取る。読みは遅めで抑制し、感情を説明しすぎない。

## 声の設計

- **ホセ**：63歳、低く乾いた男性声。疲れはあるが、感傷的に泣かない。短い沈黙を大切にする。
- **運転手A**：50代、太めの男。近所の仲間として率直だが、悪意はない。
- **運転手B**：40代、痩せた男。少し無神経に自慢してしまう。
- **老婆**：70代、穏やかで芯がある。哀れみではなく、生活者の実感として話す。
- **ラジオアナウンサー**：無機質で整った男性声。国家放送らしく硬い。

## 編集メモ

- 台詞はすべて**単独ファイル**で出力する。
- ホセは音量を上げず、沈黙を残す。感情は声より間で見せる。
- BGM：夜勤のラストのみ、低く遠いタンゴをエンジン始動後に入れる。
- 効果音：ラジオを切る音／車磨きの布／ドアの開閉／エンジン始動は、音声生成とは別トラックで処理する。
