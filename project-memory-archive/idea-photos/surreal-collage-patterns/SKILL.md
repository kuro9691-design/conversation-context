# シュールコラージュ・パターン集

## 共通する3つの根本パターン

1. **スケール崩壊** — 手・顔・物のサイズを極端にずらす（巨大な手、巨大な顔、極小の人物など）
2. **形状類似の強引な接続** — 見た目の形が似ているだけの無関係なもの同士をダジャレ的に繋げる（visual pun）
3. **コラージュの物理的な"切れ端"自体を素材化** — 紙の破れ目・切り抜きの縁そのものをモチーフにする（メタコラージュ）

当てはまるものがなければ「未分類」として、どう新しい型になりそうか一言添えること。パターンは今後増えていく前提。

## 新パターン候補（正式採用待ち）

- ミラーリング/双子化 — 人物と物が姿勢・造形を鏡合わせのように反復する
- 異質パーツの接ぎ木 — 明らかに不釣り合いな身体パーツを違和感なく接合する
- 反転ミラー世界 — 地面と空を水平線で鏡写しにし、梯子等で両世界を繋ぐ
- 多腕化/身体増殖 — 一人の人物の腕や脚を増やして同時多発的な動作を誇張する
- 遠近トリック — 奥行きのある構図で手前と奥のスケールを強制的に揃える
