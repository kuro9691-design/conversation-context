# 顧問建築士LP ボレット案

**作成日：2026-10-27**

## 使用した型

添付された動画文字起こしで実演されていた基準を使用する。

- 1行23文字以内、最大2行
- 要点だけでなく、読み手が得る利益を入れる
- 数字・損失・疑問などの具体性を持たせる
- 答えを全部書かず、続きを読みたくなる余白を残す
- 余計な助詞を減らし、心の中で音読して止まらない文章にする
- 根拠が確認できない数字や実績は断定しない

元動画で言及された有料の「ボレットフォーミュラ」本文自体は添付に含まれていないため、以下は秘密式の複製ではなく、動画内で公開された評価基準の応用である。

## 2,000万円差額事例の確認後に使う本命

下記は、同等条件、最終金額、迫谷氏の介入内容、掲載許可を確認できた場合だけ使用する。

> 見積4,000万円を精査  
> 約2,000万円差が出た理由

この本命ボレットを先頭に置き、続けて02〜07を並べる。

## LPでの配置

ファーストビュー直下に7本を一度に密集させず、3本を表示する。残り4本は、実例・サービス内容・料金の各セクション冒頭へ分散する。ボレットの役割は説明の代わりではなく、次の本文を読み進めてもらうことである。

## 自己採点

| 基準 | 判定 |
|---|---|
| 1行23文字以内・最大2行 | 合格 |
| 経営者の金額不安に直結 | 合格 |
| 利益・損失回避が伝わる | 合格 |
| 答えを出し切らず興味を残す | 合格 |
| 未確認事例を断定しない | 合格 |
