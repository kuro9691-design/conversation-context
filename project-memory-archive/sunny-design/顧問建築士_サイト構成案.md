# SUNNY DESIGN 顧問建築士サイト構成案

**作成日：2026-10-27**

## 推奨規模

本格公開時は **主要8ページ＋法定・運用2ページ**、合計10ページ前後を推奨する。市場検証段階では、この内容を1ページの独立LPへ圧縮する。

## 主要8ページ

| # | ページ | 経営者が解消する不安 | 主な内容 |
|---:|---|---|---|
| 1 | TOP | 自分の会社に関係するサービスか | メインコピー、ボレット3本、提供価値、実例導入、相談CTA |
| 2 | 顧問建築士とは | 設計事務所・施工会社と何が違うか | 発注者側の役割、中立性、利益相反、対応範囲 |
| 3 | サービス | 具体的に何を頼めるか | 見積精査、修繕判断、出店・移転、業者選定、発注者支援 |
| 4 | 事例 | 本当に効果があるか | 課題→介入→判断→結果。2,000万円差額事例は確認後に掲載 |
| 5 | 料金・契約 | いくらかかり、どこまで含まれるか | 初回相談、スポット、月額顧問、大型案件、別料金範囲 |
| 6 | ご相談の流れ | 問い合わせ後に何が起きるか | 初回相談、資料確認、提案、契約、継続支援 |
| 7 | 建築士紹介 | 誰に会社の資産を任せるのか | 迫谷氏の27年・200件超の経験、一般建築、考え方、人柄 |
| 8 | よくある質問・問い合わせ | 相談してよい案件か | 対応地域、資料、緊急対応、秘密保持、フォーム |

## 法定・運用ページ

9. プライバシーポリシー  
10. お知らせ／コラム一覧

## 段階的な制作

### Phase 1：市場検証

- 1ページLP
- 上記8ページ分の要点を縦長ページへ圧縮
- 目的はスポット相談3件・有料案件1件の獲得

### Phase 2：本格サイト

- 主要8ページ＋法定・運用2ページ
- 事例が確認できた後にCASEを独立
- 検索流入と紹介後の信用確認を両立

### Phase 3：SEO拡張

反応が取れた相談だけを個別ページ化する。

- 見積精査
- 改修・修繕相談
- 出店・移転前診断
- クリニック向け
- 介護・福祉施設向け
- 工場・倉庫向け

初期から業種別ページを量産せず、実際の相談データが出てから12〜15ページへ拡張する。

## デザイン画像の制作単位

先に作成したTOP案と同じデザインシステムで、主要8ページすべてのイメージ画像を制作可能。最初にTOP、サービス、事例、建築士紹介の4画面を揃えると、迫谷氏へサイト全体像を説明できる。
