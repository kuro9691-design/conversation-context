# SUNNY DESIGN 顧問建築士サービス 市場分析

**分析日：2026-10-27**

## 結論

市場は存在する。ただし、完全なブルーオーシャンではなく、**既存の設計監理・CM・発注者支援・建物診断を、中小企業向けに分かりやすく再商品化できる余白が大きい市場**である。

SUNNY DESIGNにとっては参入価値がある。公開情報上の「一級建築士27年・注文住宅160棟・一般建築40件・合計200件超」という経験は、顧問型サービスの信用資産になる。一方、需要は潜在的で「顧問建築士」という名前だけでは検索されにくい。最初から月額顧問を売るより、困りごとが顕在化した瞬間に買えるスポット診断を入口にし、継続契約へ移行する設計が適する。

本構想は、IT業界のベンダー見積精査・コスト最適化で用いられる「固定報酬＋削減効果に応じた成功報酬」モデルを、建築発注者支援へ応用する発想から生まれた。建築も知識の非対称性、高額発注、専門見積、ベンダー側との利害差という構造が共通しており、着眼自体は妥当である。

## 市場判定

| 観点 | 判定 | 理由 |
|---|---:|---|
| 顧客課題の強さ | 5/5 | 建築見積・法規・修繕優先順位は経営者だけでは判断しにくく、誤判断額も大きい |
| 市場の追い風 | 4/5 | 非住宅改修市場が大きく、工事費上昇で見積精査の価値も増している |
| 直接競合の少なさ | 4/5 | 広島で「法人向け顧問建築士」を明確に掲げる検索競合は目立たない |
| 代替競合の強さ | 2/5 | 工務店、設計事務所、管理会社、施工会社、積算会社、知人業者が強い代替手段になる |
| 検索需要の顕在性 | 2/5 | 顧客は「顧問建築士」より「見積が高い」「改修業者の選び方」など症状語で探す |
| 信頼獲得の難易度 | 2/5 | 企業資産と高額工事に関わるため、Webだけで即契約にはなりにくい |
| 継続収益性 | 4/5 | 多拠点・定期改修のある顧客なら月額化しやすい。単一小規模店舗はスポット向き |

**総合：参入推奨。ただし「ホームページを作れば自然流入で顧問契約が取れる」という市場ではない。**

## 需要を裏づける材料

- 国土交通省資料では、2025年度第3四半期の非住宅リフォーム・リニューアル工事受注高は2兆8,252億円、前年同期比25.5%増。建設工事費デフレーターも前年より上昇しており、発注判断とコスト管理の重要性は高い。
- 2021年の広島県内民営事業所は122,155。全事業所が対象ではないが、施設を持つ中小企業の母集団は十分大きい。
- 広島県建築士会には約1,700人の会員がいる一方、公開検索では多くが設計・施工・住宅を前面に出し、法人発注者側の中立顧問という見せ方は少ない。
- 全国には月5万円、月10万円以上の法人向け建築顧問例があり、カテゴリー自体は成立している。つまり「誰もやっていない」のではなく、「地方中小企業向けの商品設計と伝え方が未成熟」と見るのが正確。

## SUNNY DESIGNの有力な実例候補

ユーザーから、迫谷氏が施主から相談を受けた案件について、次の口頭情報が共有された。

- 当初想定していた工事費：約2,000万円
- 提示された見積：約4,000万円
- 迫谷氏への相談後に生じた差額：約2,000万円
- 施主から大変喜ばれたとのこと

この内容が同一または同等の工事範囲・品質・仕様を前提とした実績であり、資料で確認できれば、本サービスの最重要事例になる。仮に相談・精査費用が10万円なら、2,000万円の差額に対して費用は0.5%、単純な金額比は200倍である。

ただし、公開前に次を確認する。

1. 4,000万円と2,000万円で、工事範囲・仕様・数量・品質・保証がどこまで同じだったか。
2. 2,000万円は最終契約額か、再見積額か、単なる減額提示か。
3. 何を発見・変更・交渉した結果なのか。
4. 迫谷氏の助言による効果と、施主側の計画変更による効果を分けられるか。
5. 匿名事例として、金額と施主コメントを掲載してよいか。

確認できるまでは「2,000万円削減した」と断定せず、「約4,000万円の見積について相談を受け、条件整理後に約2,000万円の差額が生じた事例がある」と扱う。

## 最初に狙う顧客

優先順位は次の通り。

1. **複数施設を持つ地域企業**：クリニック・歯科、介護、保育、飲食、小売、宿泊、工場、倉庫。修繕・出店・法規・業者選定が繰り返し発生する。
2. **総務部に建築専門家がいない従業員20〜300人程度の会社**：社長または総務責任者が高額判断を背負っている。
3. **近く改修・移転・出店を予定する企業**：問題が顕在化しており、最初のスポット契約につながりやすい。
4. **税理士・保険代理店・不動産会社・金融機関の顧客企業**：信頼を借りられる紹介チャネル。工事を受注する会社は利益相反の説明が必要。

単一物件で工事予定がなく、年間相談回数も少ない小規模事業者は、月額顧問の初期ターゲットにしない。

## 商品は3段階にする

### 入口：建築セカンドオピニオン

- 初回60〜90分相談
- 見積書・提案書の簡易レビュー
- 「確認すべき点・業者に聞く質問・次の判断」を1枚に整理
- 無料ではなく、低額の有料診断にして本気度を見極める

### 中間：案件単位の発注者支援

- 複数見積の条件統一と比較
- 工事範囲・仕様・金額・工程の論点整理
- 代替案と優先順位の提示
- 必要に応じて業者打合せへ同席
- 設計、工事監理、法定点検、契約・法務判断は別業務として明確化

### 継続：企業のかかりつけ建築士

- 月次相談枠、一次判断、年次建物レビュー、修繕計画の更新
- 緊急時の初動助言と現地対応条件
- 顧問範囲を超える調査・設計・現場確認は個別見積
- 料金は面積より、保有棟数・相談頻度・訪問回数・応答時間で段階化する

### 価格の初期仮説

市場検証用の仮置きとして、次の価格帯から反応を見る。正式価格ではなく、実働時間と責任範囲を記録して調整する。

| 商品 | 仮価格（税別） | 境界 |
|---|---:|---|
| 初回相談 60分 | 10,000〜15,000円 | 資料精査・現地訪問なし |
| 見積・改修セカンドオピニオン | 50,000〜100,000円 | 資料量・工種数で個別設定 |
| 案件単位の発注者支援 | 200,000円〜 | 打合せ回数と成果物を固定 |
| ライト顧問 | 月50,000円前後 | オンライン相談中心、訪問別料金 |
| 複数施設顧問 | 月100,000円〜 | 棟数・訪問・応答条件で設計 |

値引きより、相談枠、訪問、資料レビュー、緊急対応の上限を明確にして価格差を作る。

大型案件では「着手金＋成果連動報酬」も候補になる。ただし、建築では仕様削減・品質低下・工期変更による減額と、専門的精査による削減を区別する必要がある。基準見積、同等条件、対象外項目、算定時点、報酬率、上限額を契約書で定義し、単純な削減額歩合にはしない。

## 勝てるポジショニング

中心メッセージは「工務店批判」ではなく、**経営者が安心して発注判断できる状態をつくる、企業側の建築参謀**がよい。

推奨案：

> 建てる会社を決める前に、相談できる建築士を。
>
> 見積・修繕・出店・改修を、施工会社から独立した発注者側の視点で整理します。

「工務店の言いなり」「過剰見積もりをカット」は注目を集めるが、施工会社との関係を敵対構造にし、根拠のない不正示唆にもつながる。通常訴求は「条件をそろえる」「判断材料を整える」「過不足を確認する」を使い、具体的な削減事例が確認できた場合だけ定量訴求する。

## ホームページの役割

サイトは顧問契約を直接売り切る場所ではなく、紹介を受けた経営者が信用を確認し、スポット相談を申し込む場所にする。

必要なページ順：

1. 誰の、どんな判断を支えるか
2. 施工会社・一般的な設計依頼との違い
3. 対応できる相談例
4. 実例（問題→介入→判断→結果）
5. サービス範囲と対象外
6. 料金の入口、対応地域、応答目安
7. 迫谷氏の経歴・一般建築実績・人柄
8. 初回相談フォーム

現行の住宅デザインサイトに混在させると訴求がぼやける。まずは同一ドメイン内の独立LPまたは法人向けセクションで検証し、反応が出たら独立サイトを検討する。

別ホームページという提案は戦略的に正しい。現行サイトは「理想の住まいを設計する建築家」を売り、新サービスは「企業の高額な建築判断を守る参謀」を売るため、同じトップページで両方を説明すると双方が弱くなる。最初は制作コストを抑えた独立LP、実需確認後に別ドメインまたは法人向け別ブランドへ育てる二段階が適する。

## 最大のリスク

1. **中立性の証明**：現行サイトには迫谷氏自身または特定施工会社が施工した実績表記がある。「施工を一切行わない」と言い切る前に、現在の事業構造、紹介料・提携・施工利益の有無を確認する。
2. **業務範囲の膨張**：月額定額で現地調査、見積数量査定、業者交渉、緊急出動まで含めると採算が崩れる。顧問内／別料金を契約前に分ける。
3. **削減保証の危険**：「顧問料以上を必ず削減」「過剰見積もりを排除」は保証しない。品質や将来維持費を含む総合判断として表現する。
4. **一人依存**：緊急対応を売る場合、休日・遠方・同時多発への対応条件が信用問題になる。
5. **専門領域の限界**：構造、設備、積算、消防、契約法務などは必要に応じた専門家連携を明示する。

## 90日間の市場検証

フルサイト着手前に次を行う。

1. 既存・紹介先の経営者10社へ、直近3年の建物関連の困りごとと支払経験を聞く。
2. 1ページLPと「見積・改修の初回診断」を用意する。
3. 税理士、不動産、保険、金融、商工会議所等の紹介者候補5者へ説明する。
4. スポット相談3件、有料案件1件を合格ラインにする。
5. 相談で頻出した症状語をもとに、SEO記事とサービス名を決める。

この検証に通れば本サイト化する。反応が弱い場合は「顧問」を捨てるのではなく、見積精査、改修相談、出店前診断など、最も売れた入口へ絞る。

## 最終判定

**ブルーオーシャン度は10点中7点。**

- 競合が少ないから7点ではなく、既存サービスを企業側の言葉で再定義できる余白があるから7点。
- ただし潜在需要型で、認知教育と紹介が必要なので10点ではない。
- SUNNY DESIGNは経験面で参入資格がある。成否はデザインではなく、中立性の証明、具体的な事例、商品範囲、紹介チャネルで決まる。
- 上記2,000万円差額の事例が確認・公開できれば、信用形成と支払意思の両面で市場検証を一段前進させられる。
